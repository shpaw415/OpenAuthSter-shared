# Release v0.2.1

## Overview

- /token requests now forward both client_id and copy_id while keeping the legacy cookie so existing sessions keep working.
- Client SDK gains stronger typing to reduce runtime errors and improve editor hints.

## Changes

### Fixes

- Ensure client_id and copy_id are included on /token requests and the existing cookie remains for backward compatibility.

### Enhancements

- Client methods now ship with tighter type definitions for safer, more discoverable usage.

## Upgrade Notes

- No breaking changes expected; cookie-based flows remain unchanged.
- Update to the latest package version and rerun your type-check to pick up the improved client typings.

## Verification

- Perform a /token exchange with client_id + copy_id and confirm the cookie is still accepted.
- Run the project's type-check to confirm the upgraded client types integrate cleanly.
