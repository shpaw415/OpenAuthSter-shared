# Release v0.2.1

## Overview

This patch fixes a reliability issue where `client_id` and `copy_id` could be lost during `/token` exchanges that strip cookies, and ships several type-safety improvements across the client SDK so generic session and user-info types flow end-to-end.

## Changes

### Fixes

- **`client_id` / `copy_id` now sent as query parameters** – The internal `fetcher` in `client/index.ts` appends `client_id` (and `copy_id` when present) as URL search params on every outgoing request. Cookies are still set for backward compatibility, but the server can now resolve the client even when cookies are stripped by proxies or cross-origin policies.

### Enhancements

- **`updateUserSession` accepts partial data** – The `data` parameter changed from `SessionData` to `Partial<SessionData>`, allowing callers to send only the fields they want to update instead of the entire session object.

- **`getUserById` returns fully-typed response** – The method now resolves to `UserResponseSchemaInferdType<PublicSessionData, PrivateSessionData, UserInfo>` instead of the loosely-typed `UserResponseSchemaType`, giving callers type-safe access to per-user session and provider data.

- **`parseResponseData` has an explicit return type** – The private helper now declares its return shape (`{ public, private, user_id, user_identifier, userInfo }`) with the client's generic parameters, eliminating implicit `any` leaks in downstream code.

- **New `UserResponseSchemaInferdType` generic** – Added to `database/endpoints.ts`. Carries `PublicSessionData`, `PrivateSessionData`, and `UserInfo` through the response so that `users[n].session_public`, `session_private`, and `data` are properly typed.

## Upgrade Notes

- **No breaking changes.** Cookie-based auth flows continue to work as before.
- `updateUserSession` now expects `Partial<SessionData>` – existing call-sites that already pass the full object will compile without changes.
- Run your project's type-check after upgrading; the stricter generics may surface previously hidden type mismatches.
